# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in DiskLens, please report it responsibly rather than opening a public issue.

You can report security concerns through GitHub Private Vulnerability Reporting on this repository, or by emailing the project maintainer at `spydersyrup@gmail.com`.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the behavior.
- Affected platforms (Linux, Windows, or both).

You will receive an acknowledgment within 48 hours, followed by updates on the assessment and fix schedule.
